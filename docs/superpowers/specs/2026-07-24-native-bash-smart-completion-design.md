# Native Bash 智能补全设计

## 背景与目标

LiteTerm Native 需要在本地 Bash 和 SSH 远端 Bash 中提供基于历史命令的智能补全。用户输入任意非空前缀后自动显示候选，使用上下方向键选择。第一次回车只把候选写入当前输入行，不执行命令；用户再次按回车后才由 Bash 执行。

本功能不修改本地或远端的 `~/.bashrc`，不影响 Fish、Zsh 等其他 shell，不复用现有快捷命令栏的 `native_cmd_history.json`。

## 方案选择

采用“会话级 Bash 集成 + 独立历史加载器 + Native 弹窗”的方案。

纯键盘事件推测无法可靠处理 Readline 光标移动、删除、粘贴和自动换行；修改 Readline 全局键位又会侵入用户配置。会话级集成通过私有 OSC 标记确定 Bash 提示符和输入起点，终端网格作为当前输入内容的可信来源，兼顾准确性和隔离性。

## 会话集成与生命周期

每个标签页拥有独立的 `CompletionState`，包含：

- 当前是否处于可编辑的 Bash 提示符；
- 提示符结束位置和当前输入前缀；
- 已加载历史、过滤后的候选和选中索引；
- 每个标签页随机生成的 OSC 校验标识。

本地标签页仅在 shell 路径的文件名为 `bash` 时启用。启动时使用临时 `--rcfile`：先加载用户原有 `~/.bashrc`，再安装只对当前进程有效的提示符钩子。SSH 建连后先探测登录 shell；确认是 Bash 后以临时 RC 内容启动交互 Bash，否则保持普通 shell 并禁用补全。临时文件只位于运行时目录，退出后尽力清理。

钩子在 Bash 输出提示符末尾发送带随机标识的私有 OSC。PTY 原始字节仍完整交给 Alacritty 解析；额外的流式识别器只接受固定格式、固定上限的 OSC 标记，不解析 CSI，也不生成终端响应。用户执行命令后立即进入非提示符状态；只有收到下一次有效标记才重新启用。因此在会话中执行 `fish` 或 `zsh` 后，补全自然停用。

## 历史读取与排序

新建本地标签页时异步读取 `~/.bash_history`；SSH 标签页在 SFTP 就绪后，通过扩展现有工作线程读取远端 `~/.bash_history`。读取设定大小和条数上限，不阻塞 UI，也不在每次按键时访问磁盘或网络。新标签页和 SSH 重连会重新加载。

解析时忽略空行、Bash 时间戳行和含换行的多行命令。当前 LiteTerm 会话中人工执行的单行命令，在发送回车前立即合并到内存历史。

候选采用稳定的混合排序：

1. 前缀匹配优先；
2. 其后为包含匹配；
3. 每组按最近使用顺序排列；
4. 完全相同的命令只保留最新一条；
5. 排除与当前输入完全相同的候选。

默认最多展示 8 条。

## 输入处理与弹窗

处于有效 Bash 提示符且输入非空时，Native 从 OSC 记录的输入起点读取到当前终端光标，支持 Readline 编辑和终端自动换行。输入变化后重新匹配候选。

弹窗锚定终端光标，优先显示在下方；空间不足时向上展开，并始终裁剪在终端可视区域内。样式沿用 Native 深色紧凑布局，当前候选整行高亮。

- `↑` / `↓`：仅在弹窗可见时切换候选，否则原样发送给 Bash；
- `Esc`：关闭弹窗；
- `Enter`：有选中项时发送“移动到行尾、清空整行、写入候选”的 Readline 输入序列，不发送 `\r`，随后关闭弹窗；
- 再次按 `Enter`：按现有终端逻辑发送 `\r` 并执行；
- 其他输入、退格、粘贴和光标移动：交给 Bash，终端回显后刷新匹配。

## 错误处理与安全边界

历史文件不存在、无权限、SFTP 未就绪或远端不是 Bash 时，仅禁用该标签页的智能补全，不影响终端使用。OSC 标记必须匹配标签页随机标识并满足长度限制，避免普通终端输出误触发状态。候选禁止包含 CR、LF、NUL 和其他可执行控制字符，确保第一次回车不会意外执行历史命令。

## 测试与验收

单元测试覆盖历史解析、去重、混合排序、候选上限、OSC 分片与伪造标记、输入区提取、弹窗上下翻转，以及第一次回车不包含 `\r`。集成测试覆盖本地 Bash、SSH Bash、重连、切换 Fish/Zsh、历史文件缺失和超长命令。

手工验收重点：

1. 输入任意非空前缀自动出现候选；
2. 上下键选择，第一次回车只填充，第二次回车才执行；
3. Readline 左右移动、退格、粘贴和长行换行后候选仍正确；
4. 新执行命令无需重载文件即可进入候选；
5. Fish/Zsh、普通终端输出及远端网络异常不会误触发或阻塞终端。
