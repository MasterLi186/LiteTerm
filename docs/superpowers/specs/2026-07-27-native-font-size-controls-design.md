# Native 字号默认值与联动控件设计

## 范围

本次只修改 `feat/memory-optimize` 分支的 `native-prototype/`。旧 guishell、
终端字体族、配色方案和字号合法范围不变。

## 默认值与兼容性

`DEFAULT_TERMINAL_FONT_SIZE` 从 15px 调整为 22px，并继续作为设置缺失值、
非法非有限值回退值和渲染器启动字号的唯一来源。配置文件中已经显式保存的
8–48px 合法字号保持不变，避免升级后覆盖用户选择。

## 设置面板交互

字号行采用 `− / 滑块 / + / 数值` 的单行紧凑布局。所有控件直接读写同一个
`SettingsDraft::font_size`：

- `−` 每次减 1px，最小 8px；
- 滑块连续调整 8–48px；
- `+` 每次加 1px，最大 48px；
- 数值控件保留直接输入和拖动能力，并显示 `px`；
- 到达上下界时对应按钮禁用。

按钮只修改草稿，不绕过现有“应用”与持久化流程；滑块、按钮和数值显示在同
一帧读取同一字段，因此天然联动。

## 验收

- 新默认配置与缺失 `font_size` 的配置均得到 22px；
- 显式保存的字号不被覆盖；
- 8px 时减号禁用，48px 时加号禁用；
- 任意中间值点击加减按钮改变 1px，滑块与数值立即反映新值；
- 完整 Native 构建和测试通过。
